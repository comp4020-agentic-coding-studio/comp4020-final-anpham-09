Ô ăn quan for The village meeting room

Figma: https://www.figma.com/design/ZIaWG65PezwxaqVA1cpFIJ?node-id=11-20

Three editable screen designs: opening turn, pit selected, and rules drawer. The Figma prototype demonstrates the middle-pit selection and opening/closing rules. It is a visual prototype, without a working game engine.

PNG: 1672 × 941. SVG: vector interface, editable text and embedded raster photos. Fonts: DM Sans, Libre Baskerville and Caveat.

House rules: two players; dân = 1 point, quan = 10; no mature-quan restriction; no borrowing; insufficient refill points means loss; no timer.
